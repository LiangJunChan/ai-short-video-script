# 【学习工作】谷语AI - AI短视频脚本生成平台

## 一、Demo 简介

**谷语AI** 是一款面向短视频创作者的 AI 辅助创作平台，帮助用户从灵感采集到脚本生成，实现一站式短视频内容创作。

### 核心用户
- 短视频创作者（抖音/小红书/B站等）
- 自媒体运营人员
- 内容营销团队

### 主要功能

1. **AI 语音文案提取**：上传短视频或粘贴抖音链接，自动提取语音转文字文案（支持双引擎 ASR：sherpa-onnx 低内存 / Fun-ASR 高精度）

2. **AI 文案改写与深度分析**：基于 MiniMax / 火山方舟 / Agnes 2.0 Flash 多模型，一键改写文案风格；提供文案结构分析、爆款点挖掘、选题标签推荐、口播节奏分析等深度洞察

3. **可视化脚本工作流**：基于 React Flow 的画布编辑器，支持分镜节点、AI 文案节点、AI 图片/视频生成节点、TTS 配音节点的拖拽编排，异步执行并实时展示进度

## 二、Demo 创作思路

### 灵感来源
作为短视频创作者，我经常遇到这样的痛点：看到一条爆款视频，想学习它的文案结构和口播节奏，但手动听写效率极低；有了文案灵感后，又需要在多个工具间切换（文档写脚本、AI 画图、配音软件）才能完成一个完整的短视频脚本。于是我想做一个"All-in-One"的 AI 短视频脚本创作平台。

### 想解决的问题
- **文案提取难**：手动听写 1 分钟视频需要 5-10 分钟，且容易遗漏语气词和停顿
- **创作工具分散**：脚本、配图、配音、视频生成需要在 4-5 个工具间切换
- **缺乏数据化分析**：凭感觉判断"为什么这条视频能爆"，缺少结构化分析框架

### 为什么做这个方向
短视频内容创作是一个万亿级市场，但创作者的工具链仍然非常碎片化。TRAE 的 AI 能力正好可以串联起"提取 → 分析 → 改写 → 生成"的完整工作流，让 AI 不只是聊天工具，而是真正融入创作流程的生产力引擎。

## 四、TRAE 实践过程

本项目从 0 到 1 完全基于 **TRAE Work** 完成开发，包括需求分析、技术架构设计、前后端实现、UI 设计系统、Docker 部署等全流程。

### 关键开发步骤

**步骤 1：需求分析与架构设计**
- 使用 TRAE Work 梳理产品功能清单和数据库 schema
- 确定技术栈：Go + Gin 后端 + React 19 前端 + SQLite

**步骤 2：核心功能开发**
- 视频上传 + FFmpeg 缩略图生成
- ASR 语音识别双引擎（自动按内存切换）
- AI 文案改写与深度分析（多 LLM Provider 支持）

**步骤 3：可视化工作流**
- React Flow 画布编辑器实现
- 节点类型扩展：分镜 / AI文案 / AI图片 / AI视频 / TTS
- 异步执行引擎 + 实时进度轮询

**步骤 4：UI 设计系统**
- 基于 TRAE 生成的暗色科技感设计规范（`DESIGN_SPEC.md`）
- neon-border、glassmorphism、grid-bg 等特效实现

**步骤 5：部署优化**
- Docker Compose 三服务编排
- 小内存 VPS 适配（ASR 双引擎自动切换、Chromium 省内存参数）
- 抖音反爬策略（Playwright + 多 URL 路由策略）
